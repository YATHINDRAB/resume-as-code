📦 Resume as Code — Yathindra Bolloju

Infrastructure-as-Code isn’t just for servers — it can also describe who you are as an engineer.

This repository represents my resume in YAML, using DevOps concepts such as configuration, modularity, reproducibility, and declarative infrastructure.
Instead of listing skills in a static PDF, this project expresses them as structured data that can be parsed, versioned, automated, and deployed.

🚀 Why Resume as Code?

Traditional resumes show what you know.
This repo shows how I think as an engineer:

Declarative mindset → YAML instead of paragraphs

Automation orientation → IaC concepts

Git-native portfolio → trackable changes and improvements

Full transparency → no hidden “buzzwords”

Immediate usability → can be parsed, indexed, or integrated into systems

In DevOps, everything is configuration.
This resume is too.
